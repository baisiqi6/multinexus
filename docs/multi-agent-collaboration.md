# 多 Agent 协作

多 agent 协作是 Coordinate + MultiNexus 项目执行层的一个交互面。它不是产品的
权威来源。

从当前文档开始：

1. [产品定义](product-definition.md) — 共享角色、不变量、委派边界和事实归属。
2. [MultiNexus 范围](scope.md) — 执行织物的职责和非目标。
3. [MultiNexus 架构](architecture.md) — 直接交互、Coordinate 托管执行、agentd、adapters 和 bridges。
4. [Coordinate](https://github.com/baisiqi6/coordinate) — 控制面与 operator 文档。

Discord 和 KOOK 仍然是有用的可见协作面。消息、交接或 agent 回复只有在适当的
harness、Coordinate、Git 或 forge 权威记录了它时，才成为持久的项目证据。
